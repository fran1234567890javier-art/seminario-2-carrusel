# Portrait image research and attribution

Research date: 2026-10-26

This directory contains only portrait files whose reuse terms were explicitly verified. A portrait being visible on a university, government, news, profile, or personal website does **not** by itself grant permission to copy it into this public repository. Cropping, tracing, recoloring, or otherwise editing a photograph does not remove its copyright.

## Reusable image located

### Francisco Cascales

- **File intended for this directory:** `francisco-cascales-juan-moreno-de-tejada-1779.jpg`
- **Direct downloadable image URL:** <https://upload.wikimedia.org/wikipedia/commons/4/4b/Moreno_de_tejada-cascales.jpg>
- **Source/description page:** [File: Moreno de tejada-cascales.jpg — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Moreno_de_tejada-cascales.jpg)
- **Underlying source:** Biblioteca Nacional de España; portrait prepared for the 1779 Madrid edition of *Tablas poéticas*.
- **Creators:** Antonio Carnicero (drawing) and Juan Moreno de Tejada (calcographic engraving).
- **Rights status:** Public domain. The engraving was published in 1779; Moreno de Tejada died in 1805 and Carnicero in 1814. The Commons file is hosted as free/public-domain media; the underlying work is out of copyright, including under life-plus-100-year terms, and its 1779 publication also predates current US copyright terms.
- **Redistribution in a public GitHub educational project:** **Yes.** Public-domain material may be redistributed and adapted. Attribution is not legally required for a public-domain work, but crediting the creators, source institution, and Commons description page is recommended.
- **Local download status:** Not downloaded in this run because the sandbox's network policy returned HTTP 403 for `upload.wikimedia.org`. The URL above points to the original file and can be downloaded when network access is available.

Suggested credit:

> Francisco Cascales, engraving by Juan Moreno de Tejada after a drawing by Antonio Carnicero, 1779. Biblioteca Nacional de España, via Wikimedia Commons. Public domain.

## Practical next step

For the five people without reusable portraits, request a photograph directly from the person or institution together with an explicit license such as CC BY 4.0 or CC BY-SA 4.0. Keep the written permission and record the photographer, exact license, source URL, and whether modifications were made.
